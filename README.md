
# AC-RAG

Adaptive Self-Correcting Retrieval-Augmented Generation Framework for Trustworthy Large Language Models


## Overview

This project develops an advanced Retrieval-Augmented Generation framework using:

- Qwen2.5-3B-Instruct
- FAISS Vector Database
- BM25 Retrieval
- Hybrid Retrieval
- Cross Encoder Reranking


## Current Progress

Completed:

- Local LLM deployment
- Baseline RAG
- FAISS retrieval
- Hybrid retrieval
- Reranking
